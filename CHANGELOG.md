# Changelog

All notable public changes to Pipista will be recorded here.

## 0.1.0b1 — Public Beta 1

Initial public beta preparation.

### Added

- Touch-first Pythonista interface
- Full PyPI name index with explicit synchronisation
- Universal-wheel and conservative source-archive installation
- Dependency planning, confirmation and transactional execution
- Managed dependency graph and uninstall protection
- Pythonista environment inventory
- Public GitHub project snapshot installation
- Fullscreen and panel launchers
- Detailed installation error display
- PyPI and GitHub browser links
- Staged, backup-aware public installer

### Safety

- SHA-256 verification for PyPI artifacts
- Archive path, link, size and file-count validation
- Collision detection for unmanaged files
- Import verification after installation
- Modified-file detection before uninstall
- Foreign binary filtering with native-only rejection
